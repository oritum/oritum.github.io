Личная функция одного владельца. Реальное подключение подготавливается. Чтение включается отдельно после OAuth; Calendar AI сейчас не включён.

1. Приложение и назначение

Personal Assistant Calendar — календарная функция личного Telegram-помощника. Разработчик и оператор — владелец GitHub-аккаунта oritum. Функция показывает владельцу повестку выбранных Google-календарей по его запросу.

2. Доступ к Google Calendar

Владелец предоставляет доступ через Google OAuth. Приложение запрашивает только https://www.googleapis.com/auth/calendar.events.readonly и https://www.googleapis.com/auth/calendar.calendarlist.readonly. Эти права не позволяют создавать, изменять или удалять события.

Право чтения событий технически охватывает доступные аккаунту календари. Приложение загружает события только из сохранённого выбора владельца. Список календарей используется для выбора; запись основного календаря — для определения подключённой учётной записи.

Используются идентификаторы и названия календарей, идентификатор подключённого аккаунта, идентификаторы событий, названия, начало и конец, часовой пояс, статус и признак события на весь день. Описания событий, участники, вложения и поля ссылок не запрашиваются для повестки. Внешние ресурсы из названий событий не открываются.

Пароль вводится на стороне Google. Desktop OAuth client JSON вводится в защищённой локальной форме, не в Telegram и не на этом сайте.

3. Использование и передача

Данные нужны для подключения выбранного аккаунта, выбора календарей, загрузки и сортировки событий, показа повестки и локального блока общей сводки. Повестка и названия календарей показываются владельцу в его личном Telegram-чате. Google обеспечивает источник данных и авторизацию, Telegram — доставку и отображение.

События не публикуются на этом сайте или в публичном репозитории. Calendar credentials не передаются в Telegram или AI. Календарные снимки не добавляются в память обычного диалога.

Передача календаря в OpenAI сейчас не включена. Возможность AI-выжимки требует отдельного согласия владельца на условия обработки и состав данных, а затем отдельного запроса. OAuth и включение чтения этого согласия не заменяют.

При отдельно разрешённой AI-выжимке передаются период и время снимка, названия, начало и конец, timezone, статус и признак «весь день». Google IDs, названия календарей, описания, участники, вложения и поля ссылок не включаются. URL и очевидные секреты внутри названий фильтруются эвристически; обнаружение любого секрета не гарантируется.

Поставщики обрабатывают переданные данные по своим применимым условиям. Локальное удаление не удаляет уже доставленные сообщения из Telegram. Параметр store=false будущего отдельно разрешённого AI-запроса сам по себе не обещает отсутствия внешнего хранения.

4. Локальное хранение

Учётные данные Google OAuth, настройки, выбор календарей, timezone, согласия и последний полный снимок событий хранятся зашифрованно на устройстве владельца. Полные ответы Google API на диск не сохраняются.

  • Снимок используется до 24 часов. На работающем боте срок проверяется раз в минуту; после простоя — при следующем чтении.
  • Учётные данные и настройки сохраняются до локального отключения Calendar.
  • Технические записи календарных AI-попыток без содержимого событий при наличии сохраняются до 30 дней. Отключение не сбрасывает счётчики.

Удаление логическое: прежние записи могут сохраняться в файлах базы и резервных копиях дольше срока рабочего кэша. Копиями управляет владелец. Telegram хранит доставленные сообщения по своим правилам.

5. Согласие, пауза и отключение

После OAuth чтение и Calendar AI изначально выключены. В разделе Календарь владелец отдельно подтверждает включение чтения, смену набора календарей или timezone. Выбор ограничивает запросы приложения, а не права уже выданного Google-токена.

Пауза чтения, смена календарей или timezone удаляет локальный снимок. Локальное отключение Calendar удаляет его credentials, настройки, согласия и кэш из рабочей базы; подключение Gmail управляется отдельно.

Локальное отключение не отзывает Google grant. Доступ отзывается отдельно в подключениях Google Account. Владелец должен проверить, какое приложение отключает: отзыв Google может затронуть все OAuth clients одного Cloud project. Calendar использует отдельный проект от Gmail.

6. Ограничение использования

Данные используются только для описанной личной календарной функции. Приложение не продаёт данные, не использует их для рекламы, рекламного профилирования или общего обучения моделей.

Обработка Google API data должна соответствовать Google API Services User Data Policy, включая Limited Use, и Google Workspace User Data Policy. Перед будущим включением AI условия поставщика проверяются и согласуются отдельно.

7. Этот сайт и контакт

Сайт содержит только описание и документы. Здесь нет формы OAuth, собственной аналитики или рекламных скриптов; сайт не получает события, Desktop client JSON или OAuth credentials. Хостинг GitHub Pages обрабатывает технические данные посещения, включая IP-адрес, согласно своей политике.

Для вопросов используется адрес поддержки на экране согласия Google для Personal Assistant Calendar. Публичная страница оператора — github.com/oritum.

Изменения обработки отражаются в этой политике до включения соответствующей функции. Дата действующей редакции указана выше.
